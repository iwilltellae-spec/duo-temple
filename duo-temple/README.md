# Duo Temple

Вертикальный кооперативный puzzle-platformer под Telegram WebApp: Огонь + Вода, два телефона, одна комната.

Это не копия Fireboy and Watergirl и не использует чужие ассеты. Визуал сейчас полностью процедурный: Canvas, градиенты, частицы, мобильный UI.

## Что уже есть

- Вертикальный формат 9:16 для Android/iPhone.
- Полностью автономный клиент без CDN и внешних картинок.
- Красивый canvas-визуал: храм, свет, частицы, персонажи, кристаллы, ворота, опасности.
- Touch-управление.
- Тренировочный режим.
- WebSocket-мультиплеер через отдельный сервер.
- Комнаты на 2 игрока: `fire` и `water`.
- Подготовка под Telegram WebApp: `Telegram.WebApp.ready()`, `expand()`.
- Подготовка под Vercel + Render.

## Структура

```text
duo-temple/
  client/
    index.html        # вся игра, готова для Vercel/static hosting
  server/
    server.js         # WebSocket-сервер комнат
    package.json
    render.yaml
  package.json
  vercel.json
```

## Локальный запуск клиента

Самый простой вариант:

```bash
cd duo-temple/client
python3 -m http.server 5173
```

Открыть:

```text
http://localhost:5173
```

## Локальный запуск сервера

```bash
cd duo-temple/server
npm install
npm start
```

Сервер поднимется на:

```text
ws://localhost:10000
```

В игре в поле `Render WebSocket URL` вставить:

```text
ws://localhost:10000
```

## Деплой клиента на Vercel

1. Залить папку `duo-temple` на GitHub.
2. В Vercel выбрать репозиторий.
3. Framework Preset: `Other`.
4. Output/static директория: `client`.
5. После деплоя открыть Vercel URL.

Если Vercel попросит команду сборки — можно оставить пустой, потому что клиент статический.

## Деплой сервера на Render

1. Создать новый Web Service.
2. Root Directory: `server`.
3. Build Command:

```bash
npm install
```

4. Start Command:

```bash
npm start
```

5. После деплоя Render даст URL вида:

```text
https://duo-temple-server.onrender.com
```

В игре нужно вставлять WebSocket URL:

```text
wss://duo-temple-server.onrender.com
```

## Как играть онлайн

1. Игрок 1 открывает игру.
2. Вставляет `wss://...onrender.com` в поле сервера.
3. Нажимает `Создать за Огонь` или `Создать за Воду`.
4. Получает код комнаты.
5. Нажимает `Копировать ссылку` и отправляет второму игроку.
6. Игрок 2 открывает ссылку и подключается.

## Управление

- На телефоне: нижние кнопки `←`, `→`, `↑`.
- На клавиатуре: стрелки / WASD / Space.
- В режиме `Тренировка` верхняя левая плашка переключает героя: `Огонь` ↔ `Вода`.

## Уровни

Сейчас в игре 11 уровней: первый учебный и 10 следующих.

1. `Плиты стихий` — понятный tutorial: маршруты, стихии, две финальные плиты.
2. `Раздельный подъём` — два параллельных маршрута, первые более опасные лужи.
3. `Два замка` — последовательные замки: сначала локальные плиты, потом общий замок.
4. `Перекрёстная дверь` — игроки читают уровень по цветам и держат две верхние плиты.
5. `Центральный мост` — две боковые плиты открывают центральные проходы, затем общая плита.
6. `Первый пазл` — четыре цветных замка и финальная дверь.
7. `Лестница замков` — последовательность из трёх замков: огонь, вода, нейтральная печать.
8. `Обмен сторонами` — герои должны подняться и фактически поменяться сторонами.
9. `Четыре печати` — закрепление четырёх цветных плит без текстовых подсказок.
10. `Узкий храм` — более тесные центральные проходы и опасности на маршруте.
11. `Двойной ключ` — две пары цветных ключей плюс нейтральная финальная печать.

Логика читается без текстовых подсказок: цвет плиты показывает, кто должен её нажать; цвет лужи показывает, для кого она безопасна.

В тренировке верхняя левая плашка переключает героя. Верхняя правая плашка перезапускает текущий уровень.

Для быстрой проверки на клавиатуре:

- `R` — перезапуск уровня;
- `N` — следующий уровень;
- `P` — предыдущий уровень.
